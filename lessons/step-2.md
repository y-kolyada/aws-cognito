## Хочу

Сайт `devops-aws-cognito` получает четыре полностью написанных содержательных главы `ru/06.html` - `ru/09.html`, раскрывающих расширенную инженерную механику Cognito:

- 06: События и триггеры (LambdaConfig: 15 триггеров жизненного цикла, синхронные и асинхронные события, Pre Sign-up валидация и авто-подтверждение, Pre Token Generation v1 и v2 для динамического обогащения claims, Post Confirmation, Custom Message).
- 07: Identity Pools и STS (Federated Identities, архитектура обмена токенов на временные AWS credentials, Authenticated и Unauthenticated роли IAM, правила сопоставления ролей RoleMappings по клеймам токена, Role Trust Policy для cognito-identity.amazonaws.com).
- 08: Безопасность и WAF (Advanced Security Features ASF, режимы OFF/AUDIT/ENFORCED, адаптивная риск-аутентификация Adaptive Authentication, обнаружение скомпрометированных паролей Compromised Credentials, прямая интеграция User Pool с сетевым экраном AWS WAFv2).
- 09: Лимиты и экономика (модель тарификации MAU, тарифные уровни Essentials и Plus, расчет и оптимизация затрат на SMS MFA, защита от SMS Toll Fraud, региональные квоты вызовов API Identity Provider, стратегии кэширования).

Каждое утверждение об инструменте, вынесенное на эти страницы, доказывается выполнением на хосте без обращения к AWS: формы параметров, структуры JSON и допустимые значения берутся из `aws cognito-idp ... --generate-cli-skeleton`, `aws cognito-identity ...`, локального разбора `jq` и справки AWS CLI.

4. **Схемы (inline SVG) не внедряются.** Текст страниц самодостаточен без схем; схемы усиливают материал на финальном этапе (Шаг 5).

6. **Ни одна проверка не обращается к живому AWS.** Проверяются только структуры CLI, спецификации и числовые лимиты.
