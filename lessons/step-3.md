## Хочу

Сайт `devops-aws-cognito` получает три полностью написанных практических главы `ru/10.html` - `ru/12.html`, охватывающих полный спектр прикладных сценариев эксплуатации Amazon Cognito:

- 10: Примеры · Noob (7 базовых сценариев):
  1. Создание User Pool через Terraform с подтверждением email и надежной политикой паролей.
  2. Настройка App Client для SPA с протоколом Authorization Code Grant и защитой PKCE.
  3. Привязка домена Hosted UI со стандартным префиксом Cognito.
  4. Регистрация и подтверждение пользователя через AWS CLI (`sign-up` и `confirm-sign-up`).
  5. Клиентская аутентификация по протоколу Secure Remote Password (`USER_SRP_AUTH`).
  6. Активация программного токена TOTP MFA через консоль и CLI.
  7. Защита от перечисления пользователей через флаг `PreventUserExistenceErrors = ENABLED`.

- 11: Примеры · Pro (7 промышленных сценариев):
  1. Интеграция Cognito User Pools Authorizer с Amazon API Gateway (REST API).
  2. Развертывание JWT Authorizer на HTTP API (API Gateway v2) с валидацией audience и issuer.
  3. Аутентификация на слушателе балансировщика ALB через Hosted UI с передачей клеймов в бэкенд.
  4. Динамическое обогащение клеймов токена через Pre Token Generation v2 Lambda Trigger.
  5. Корпоративный федеративный вход через Google Workspace / OIDC с сопоставлением атрибутов.
  6. Гранулярный доступ пользователей к приватным каталогам Amazon S3 через Identity Pools и SigV4.
  7. Эшелонированная защита User Pool от атак подбора паролей через AWS WAFv2 WebACL.

- 12: Примеры · IGL (7 архитектурных сценариев системного уровня):
  1. Беспарольный вход по Email OTP через кастомный поток аутентификации (триада Define/Create/Verify Auth Challenge).
  2. Бесшовная миграция пользователей «на лету» из legacy-базы через триггер User Migration.
  3. Мультиарендная B2B-федерация с динамическим выбором IdP по корпоративному домену клиента.
  4. Интеграция FIDO2 Passkeys и WebAuthn в интерфейсе Managed Login для защиты от фишинга.
  5. Защита от международного телефонного мошенничества SMS Toll Fraud через гео-валидацию в Pre Sign-up.
  6. Ротация Refresh токенов с обнаружением повторного использования и отзывом скомпрометированных сессий.
  7. Комплексный аудит угроз Credential Stuffing и скоринг рисков в Amazon CloudWatch и Athena.

Посадочная страница `ru/index.html` обновляется снизу вверх: пункты 10, 11 и 12 в списке разделов приводятся в точное соответствие с реализованными практическими сценариями.

Каждое утверждение об инструменте, вынесенное на эти страницы, доказывается выполнением на хосте без обращения к AWS: формы параметров, структуры JSON и допустимые значения берутся из `aws cognito-idp ... --generate-cli-skeleton`, `aws apigateway ...`, `aws elbv2 ...`, локального разбора `jq` и справки AWS CLI.
